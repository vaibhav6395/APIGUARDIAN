# Security and responsible use

APIGUARDIAN is intended for defensive authorization validation.

- Test only systems you own or are explicitly authorized to assess.
- The default demonstration target is local and synthetic.
- Do not upload production secrets, personal data or customer records.
- Do not expose the demo API to the public internet.
- Keep local environment files out of Git.
- Review findings manually before changing access policies.
- Never treat a single automated result as proof that an application is secure.

## Reporting a vulnerability
Do not publish exploit details for a live system. Contact the repository maintainer privately through GitHub's security reporting feature when available.
